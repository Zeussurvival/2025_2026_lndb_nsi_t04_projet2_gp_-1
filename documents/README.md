# RE:LIFE
RE:LIFE est un jeu interactif où le joueur doit netooyer une planète dans l'univers. Ce jeu utilise les modules pythons suivant: Pygame et numpy

## 🛠 Prérequis

### Configuration logicielle
- **OS** : Windows/Linux (version post-2020)
- **Python** ≥ 3.13.1
- **Modules** : Voir `requirements.txt`
