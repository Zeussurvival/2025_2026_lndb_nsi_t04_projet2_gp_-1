# 🌍 RE:LIFE

RE:LIFE est un jeu vidéo développé dans le cadre du thème « Nature & Informatique ». Le joueur doit restaurer une planète polluée en collectant des ressources et en utilisant des machines pour recycler, transformer et purifier l’environnement.

## 🚀 Pour commencer

Pour bien débuter avec le projet, il est recommandé de comprendre le fonctionnement global du jeu : exploration, collecte de ressources et utilisation de machines pour restaurer l’environnement.

## ⚙️ Pré-requis

- Python
- Un ordinateur capable de faire tourner le projet

## 📦 Installation

1. Télécharger ou cloner le projet
2. Ouvrir le projet avec votre éditeur Python préféré
3. Installer les dépendances dans requirements.tkt

## ▶️ Démarrage

- Ouvrir le projet dans le logiciel
- Lancer le main
- Cliquer sur "Play" pour démarrer le jeu
